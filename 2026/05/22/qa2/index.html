做题汇报：P5731 【深基5.习6】蛇形方阵

一、题目

题目来源：洛谷 P5731 【深基5.习6】蛇形方阵
题目描述：
给出一个不大于 9 的正整数 ( n )，输出 ( n \times n ) 的蛇形方阵。
从左上角填上 1 开始，顺时针方向依次填入数字。每个数字占用 3 个字符，前面使用空格补齐（即右对齐，宽度为 3）。

输入格式：一个正整数 ( n )。

输出格式：( n ) 行，每行 ( n ) 个右对齐宽度为 3 的数字。

样例输出：

数据范围：( 1 \le n \le 9 )

二、解题思想

这类题目属于二维数组螺旋填充问题，核心思想是模拟，即一步一步地按照规则将数字填入矩阵。

我们可以在脑海中想象一个“小人”站在矩阵左上角，手里拿着一个数字，每走一步就把当前数字放在脚下，然后数字加 1。小人的行走规则是：

  1. 一直沿当前方向走；
  2. 当前方没有路了（碰到边界或已经填过数的格子），就顺时针转一个方向再继续走。

这种“方向+拐弯”的模拟非常适合用方向数组来实现。

方向数组

定义四个方向的变化量，顺序为：右 → 下 → 左 → 上（顺时针一圈）。

  • 向右走：行变化 0，列变化 +1 → dx=0, dy=1
  • 向下走：行变化 +1，列变化 0 → dx=1, dy=0
  • 向左走：行变化 0，列变化 -1 → dx=0, dy=-1
  • 向上走：行变化 -1，列变化 0 → dx=-1, dy=0

用数组表示：

当前方向用一个变量 d 来表示（0~3），顺时针转方向就是 d = (d + 1) % 4。

如何判断“该转弯了”？

每走完一步后，我们先“试探”沿当前方向再走一步会到哪里 (nx, ny)。
如果 (nx, ny) 满足以下任一条件，就要转弯：

  • 超出了矩阵的边界（nx<0 或 nx>=n 或 ny<0 或 ny>=n）
  • 这个格子已经被填过数字了（a[nx][ny] != 0）

转弯后，重新计算新的下一步位置，再正式移动过去。

循环执行

总共需要填 ( n \times n ) 个数字，用一个 for 循环从 1 到 ( n^2 ) 即可。每次填完当前数字，更新位置到下一个格子。

最后，按照每行右对齐宽度为 3 的格式输出。

三、Python 代码实现

关键点小结

  1. 模拟思想：不需要复杂的数学公式，严格按照题目描述的“走法”在代码中复现。
  2. 方向数组：用 dx、dy 存储四个方向的步进值，配合方向变量 d 实现行走和转弯。
  3. 边界与重复判断：试探下一步位置是否合法，不合法则顺时针换向，这是螺旋填充的核心逻辑。
  4. 输出格式：f"{val:3}" 格式字符串实现宽度为 3 的右对齐，不足位补空格，完全符合题目要求。

这种思路不仅适用于本题，也同样可以解决任何类似的螺旋矩阵、蛇形填数问题。通过改变方向顺序和试探条件，还能灵活处理逆时针、从中心向外等变体。
