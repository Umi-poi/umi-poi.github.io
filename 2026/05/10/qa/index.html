做题汇报：P1307 [NOIP 2011 普及组] 数字反转

一、题目

题目来源：洛谷 P1307（NOIP 2011 普及组）
题目描述：给定一个整数 ( N )，将其各个数位上的数字反转得到一个新数。新数需满足整数的常见形式：除非原数为零，否则反转后最高位数字不能是零。
数据范围：(-1,000,000,000 \le N \le 1,000,000,000)。

样例：

  • 输入 123 → 输出 321
  • 输入 -380 → 输出 -83（去掉反转后的前导零，保留负号）

二、解法

解法一：字符串处理（推荐）

思路：将输入视作字符串，利用 Python 切片反转，然后处理符号和前导零。

步骤：

  1. 读入字符串，判断首位是否为负号 '-'。
  2. 若为负数，先保留符号，对 [1:] 部分进行反转；若为正数，直接反转整个字符串。
  3. 反转后的数字部分可能包含前导零，用 .lstrip('0') 去除。
  4. 若去除后变为空字符串（说明原数各位全零），则令数字部分为 '0'。
  5. 输出符号 + 数字部分。

复杂度：(O(L))，(L) 为输入字符串长度，常数较小。

解法二：数学运算（不依赖字符串）

思路：用取模和整除逐位提取个位数字，构建反转后的数值。需要单独记录符号，最后再乘回。

步骤：

  1. 读入整数 ( N )。
  2. 若 ( N = 0 )，直接输出 0 并结束。
  3. 记录符号 sign = 1（正）或 sign = -1（负），取绝对值 abs(N)。
  4. 初始化 rev = 0，循环 while n > 0：
    • rev = rev * 10 + n % 10 （将个位弹出并拼接到 rev 末尾）
    • n //= 10
  5. 输出 sign * rev。

三、思想分析

1. 核心问题分解

  • 反转数位：本质是逆序处理数字的每一位。
  • 符号处理：负数需保留负号，正数忽略。
  • 前导零消除：反转后若产生前导零（如 -380 → -083），需去掉多余的零，但要保证数字至少有一位（输入为 0 时）。

2. 字符串法思想

  • 直接利用 Python 字符串的切片逆序 [::-1]，一步完成数位反转。
  • 通过 .lstrip('0') 高效去除前导零，比手动循环更方便。
  • 是一种 “先表示，后处理” 的思维，适合位数不多的整数（本题 10 位以内完全无压力）。

3. 数学法思想

  • 模拟十进制数位重组，用 取模与整除 逐位剥离并构造新数。
  • 由于整数运算天然忽略高位零（083 在数值上就是 83），前导零被自动消除，无需额外处理。
  • 体现了 “数值计算” 的思维方式，更贴近底层逻辑，不需要字符串转换。

4. 通用技巧

  • 遇到整数反转类问题，务必注意 整数零的特殊性，避免输出空字符或变成 -0。
  • 在任意语言中，字符串法通常更易读；数学法更通用且节省内存。

总结：本题是经典的入门模拟题，考察对数字数位的操作能力。两种解法均能完美通过，推荐初学者先掌握字符串法，再理解数学法的内在逻辑，以加深对进制和位权的认识。
