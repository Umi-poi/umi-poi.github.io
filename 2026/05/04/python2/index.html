Python —— 对象的可变与不可变

作者: umi
发表于2026-05-04
更新于2026-05-04
Python算法

在 Python 中，我们常说的“可变”与“不可变”其实是指对象（值）本身能否被修改，

一、不可变对象

一旦创建，其内部状态就不能再改变。任何看起来“修改”它的操作，实际都会返回一个全新的对象。

1. 常见不可变类型

  • 数字：int、float、complex、bool（bool 是 int 的子类）
  • 字符串：str
  • 字节串：bytes
  • 元组：tuple
  • 冻结集合：frozenset

2. 如何体现“不可变”

通过 id() 观察内存地址的变化

元组不允许赋值修改其元素

但注意：如果元组里包含可变对象（如列表），元组本身仍然不可变（元素引用不变），但那个可变对象的内容是可以改变的：

这体现出不可变约束的是引用关系，而非被引用对象的内部状态。

二、可变对象

对象创建后，其内部状态可以被直接修改，而对象的内存地址不会变化。

1. 常见可变类型

  • 列表：list
  • 字典：dict
  • 集合：set
  • 字节数组：bytearray
  • 多数自定义类的实例（默认可变）

2. 如何体现“可变”

操作前后 id() 不变

共享引用时的副作用

字典、集合等也是如此

三、一眼分清：观察操作是原地修改还是返回新对象

  • 返回新对象的方法 → 常用于不可变类型
    例：str.upper()、str.replace()、整数运算 +、tuple() 等。
  • 原地修改且返回 None 的方法 → 常用于可变类型
    例：list.append()、list.sort()、dict.update()、set.add() 等。

判断技巧：在交互环境或代码里用 id() 检验，或者看操作后原变量是否改变。

四、实际影响

  • 不可变对象是可哈希的 → 可作为字典的键、集合的元素（如 int、str、tuple）。
  • 可变对象不可哈希 → 不能当键或集合元素，否则会因内容变化导致查找异常。
  • 函数传参时：传入不可变对象，函数内修改不影响外部（因为会新建对象）；传入可变对象，函数内原地修改会直接影响外部数据。

总结：Python 的“可变/不可变”本质是对象能否原地修改。用 id() 看地址是否改变，是区分它们最直观的方法。理解这一点有助于避免引用陷阱，并正确使用字典键、函数参数等。
